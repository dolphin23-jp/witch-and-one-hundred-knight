# Drive の受け口（Apps Script）

Drive コネクタは 10MB を超える音声を読み込めず、大きい音声を書き込むこともできない。
そのため「魔女と百騎兵 原作音源」フォルダの中だけを読み書きする小さな受け口を Apps Script で作り、
クラウドセッションから `tools/drive.py` で使う。

- 読み書きできるのは「魔女と百騎兵 原作音源」フォルダの中だけ（コードに固定）。
- 呼び出しには鍵が要る。鍵は最初の呼び出しで作られ、フォルダ内の `Claude受け口_鍵.txt` に置かれる。
  セッションは Drive コネクタでこのファイルを読んで使う。URL だけでは何もできない。
- 受け口の URL は `pipeline/config.yaml` の `drive_bridge.url` に書く。

## 置き方（1回だけ、iPad で5〜10分）

1. https://script.google.com を開き「新しいプロジェクト」。
2. 最初からあるコードを全部消し、`setup/drive_bridge.gs` の中身を貼って保存（プロジェクト名は「Claude 受け口」など）。
3. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」→「アクセスを承認」→ 自分のアカウント。
   「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」。
   自分で作ったスクリプトなので、この表示は想定どおり。
5. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーして、チャットに貼る。

## コードを直したとき

「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。URL は変わらない。

## 止めるとき

「デプロイ」→「デプロイを管理」→「アーカイブ」。`Claude受け口_鍵.txt` を消すと鍵も使えなくなる
（作り直すときはスクリプトのプロジェクトの設定 → スクリプト プロパティの `KEY` も消す）。
