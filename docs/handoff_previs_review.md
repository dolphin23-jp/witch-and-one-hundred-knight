## 直し方の手順（前のセッションで固まったもの）
1. `episodes/A/scenes/<シーン>/blocking.yaml` を直す（カメラは `cam_keys`、人物は `keys`、映す人物は `only`）。
2. `python tools/frame_check.py episodes/A/scenes/<シーン> <カット> --step 2 --all` で、人物の画面上の位置（s: -1 左端〜+1 右端、足・頭の縦位置、距離）を確かめる。帽子込みのメタリカは約2.4m（幻影は浮くので約3m）と大きいので、カメラが近すぎになりやすい。× は only にない人物の映り込み。
3. `python tools/staging.py episodes/A/scenes/<シーン>` で軸・飛び・重なり・カメラの単調さ（同じ向き ±30° が3カット続くと警告）を 0 にする。
4. ショットファイルを作り直す: `python tools/new_shots.py --plan <計画> --force episodes/A/scenes/<シーン>`。計画の YAML（カットの秒・lead・台詞の割り当て）は前のセッションの作業用フォルダにあり、引き継げていない。ショットファイルの camera.move だけなら手で直してもよい。new_shots を使うなら、既存のショットファイル（id・sec・timing.lead・dialogue）から計画を作り直す。
5. 下絵: `$VENV/bin/python tools/previs.py episodes/A/scenes/<シーン> <カット>… --motion 0.5 --size 640x360`（0.5秒ごとのコマ、`previs/<シーン>/<カット>_motion.jpg`）で確かめてから、`--size 640x360 --fps 8`（下絵動画と確認画像）。最後に `python tools/previs_reel.py episodes/A/scenes/<シーン>` で通しを作り直す。
6. `python tools/black_check.py <シーン>…` で真っ黒なコマ（カメラが壁・岩・草むらの中）がないか確かめる。previs.py も描いた時点で警告する。
7. コミットは `git add -f previs/<シーン>/...`（previs の一部は `.git/info/exclude` で外していたことがある。新しいクローンでは不要かもしれない）。

`$VENV` はセッションごとに `python3 -m venv` して `pip install bpy pyyaml pillow numpy`。Cycles の CPU で 640x360 は1フレーム約1.2秒（10秒のカットの動画で約2分、0.5秒ごとのコマで30秒〜1分、場面まるごとの動画で30分〜1時間）。

## 気をつけること
- クラウドのコンテナは、何もしていない時間が続くと作り直され、裏で動かしている描画が止まる。長い描画は Monitor で終わりを待つなど、ターンの中にいると止まりにくい。止まったら残りのカットから描き直す。
- `pkill -f` は自分のシェルを巻き込むことがある。止めるときは PID で。
- 実行中の sh スクリプトを `sed -i` で書き換えても、動いている方には効かない（作り直して起動し直す）。
