## 3b. 顔の向き・イマジナリーライン・帽子のつば（2回目の見直し、2026-11-07）

描き直した A08 を見て、上の測定では見つからない問題が3つあった:

1. **カメラが顔の反対側にある**（顔が向こう向き）。A08-005「寄り・ルッキーニィ」（心の声で瘴気に顔をしかめる）は、しかめ面のはずが頭の後ろしか写らない。上の測定は顔の位置と、ほかの物でふさがれるかだけで、顔がどちらを向いているかを見ていなかった。
2. **本人の帽子のつばが顔を隠す**。A08-007「あん？」は、見下ろす姿勢（頭を 32 度うつむく）で、メタリカの大きなつば（半径 0.38m）が、低いカメラからの顔をすっかり隠していた。上の測定は本人の帽子・髪を「隠す物」に数えていなかった。
3. **イマジナリーライン（180 度ルール）を越える**。向き合う二人を続けて映すとき、カメラが二人を結ぶ線の反対側へ飛ぶと、二人が同じ向きを見ているように見える。A08b-024（北東から、画面の右を見るルッキーニィ）→ A08b-026（南西から、終わりのメタリカも画面の右を見る）。

## 4. 顔と会話の芝居

- 表情の 10 種: neutral（ふつう）・smile（笑み）・grin（にやり、キヒヒ）・angry（怒り）・shout（叫ぶ）・sad（悲しみ）・surprised（驚き）・tired（疲れ）・shy（照れ、頬が赤い）・annoyed（呆れ）。
- 台詞の文で決めた表情（全台詞 1,268 本）: ふつう 1,031・にやり 70・驚き 68・叫ぶ 60・呆れ 15・疲れ 12・笑み 12。はじめ内容の言葉（「疲」「泣」「怒」）でも決めていたが、「お疲れ様」「泣き虫ベルダ」「怒ってたなぁ」を取り違えたので、台詞は感動詞と記号だけにした。
- 決めた表情を変えたいカットは、blocking の keys に `expr: angry` のように書く（その時刻から次の expr まで）。

## 5. 場面のつなぎ

`episodes/A/transitions.yaml` に、境目ごとのつなぎ方と理由を書いた。考え方:

- 同じ時間・同じ所で動きが続く → **カット**（動きでつなぐ）: A04→A05、A07→A08、A21→A22、A26→A27、A29→A30、A30→A31、A31→A32、A35→A36
- 同じ所で少し時間が経つ・形で合わせる → **溶かす**: A01b→A02、A05b→A06（窓明かりから上がった星空と、星空から下りる頭を重ねる）、A14→A15（夕日と夕日）、A28→A29（霧）ほか
- 時間が飛ぶ・章の終わり・余韻 → **暗転**: A02→A04（旅）、A08→A08b、A08b→A09、A17→A18（長い暗転で高笑いを残す）、A32→A33（6章の終わり）ほか
- 光でつながる → **白く飛ばす**: A01→A01b（扉を開け放つ翠の光）、A12→A13（扉の外の光へ）、A23→A24（空の裂け目）、A27→A28（門の光）
- 旅で場所が変わる → **ワイプ**（動く向き）: A09→A10、A10→A11、A19→A20、A36→A37、A39→A40 ほか
- 音: A16→A17 は「う、うるさいっ！」で切って夜会の魔女の笑い声を先に出す（J カット）。A17→A18・A32→A33 は高笑いや BGM を暗転の中へ残す（L カット）

確認用の動画: `previs/transitions/<前>-<次>.mp4`（前の場面の終わり 5 秒＋次の場面の頭 5 秒）と、全部を続けた `previs/transitions/transitions_all.mp4`。A01→A01b は、A01 の書き出し（Animatic）がこの作業の場所になく、A01 の立ち位置が古い書き方で下絵の道具で描けないので、確認用の動画は作っていない（Animatic で確かめる）。
