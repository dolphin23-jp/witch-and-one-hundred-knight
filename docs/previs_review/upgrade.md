# 下絵（previs）の見直しと大幅なアップグレード（2026-11-06〜）

ユーザー指示（2026-11-06）: 「ここまでのprevisについて、見直し、大幅なアップグレードをして欲しい。特に、アニメーションとして面白い絵を見せられることが重要。戦闘シーンなど。時間が元のものより伸びても構わない。」
作業ブランチ `claude/previs-upgrade`。D-062 の 3D の段階（クレジット 0）。

## 1. 見直し: 何が弱かったか

全場面（A05b〜A40、通しの下絵 計約128分）の下絵と道具を見て、次の点が「アニメとして面白い絵」を妨げていた。

| # | 弱点 | 具体例 |
| --- | --- | --- |
| 1 | 人形に脚・ひじ・ひざ・背骨がない（円柱の胴・球の頭・棒の腕）。しゃがむのは体を縦に縮めるだけ | 斬る・跳ぶ・着地・宙返り・吹き飛ぶが読めない。A07-016（目に剣を突き立てる）は、球の上に青い円柱が乗っているようにしか見えない |
| 2 | 姿勢がキーの中ほどで急に切り替わる。止まっていても歩く姿勢なら足踏みする | 溜め（予備動作）→ 打ち込み → 振り抜きの「間」が作れない |
| 3 | 当たる瞬間の見せ方がない（閃光・止め・白黒のコマ・集中線・破片・土煙・衝撃の輪・剣の軌跡） | 斬っても当たった感じがしない。A07-011 の火花は小さな光る球だけ |

| 5 | 描画が遅く（Cycles・CPU で 1コマ約6秒）、確認用は 1秒6〜8コマ・ざらつき・暗い | 速い動きの間合いが確かめられない |
| 6 | 戦いが短い | A31 の戦い約20秒（設計の見込み約40秒）、A35 約13秒、A14 約17秒。手数が少なく、ピンチ → 逆転の流れがない |
| 7 | 砂食みが「灰色の球の列」で、頭の向き・目・口がない | 目に剣を突き立てる、かみつく、吠えるが読めない |
