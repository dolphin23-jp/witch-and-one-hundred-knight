## 5. 確かめていないこと

- リポジトリの下絵の動画と測定は、描き直し・測り直していない。目印・横の角度を使った判定は、測り直したカットから効く。
- 描いて確かめたのは作業用の場所の小さい画（Cycles・320x180）だけ。Workbench（EGL）では描いていない。
- `aim: eyes` は下絵（previs.py）だけが目の位置を知る。略図・静止画の指示（staging.py）、frame_check.py、camera_room_check.py は look_h（なければ背の 0.75）で計算するので、`aim: eyes` を書いたキーでは少しずれる。
- 顔のない人物（シモベ・からくり人形など）には目印がなく、今までどおり頭の真ん中への線で測る。
- 帽子の形（沼のテレッサ）、blocking への軸の宣言、描き直し、mp4 の置き場所は、オーナーの判断待ちで止めている。
