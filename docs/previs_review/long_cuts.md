## A17-026「寄り・泣くメタリカ」（21.6 秒、tc 258.6）

台詞（原作の声）: L526「うるさい……」0.3〜7.0 秒、L527「くそっ……」7.2〜11.8 秒、L528「あんなヤツらに……」12.0〜21.0 秒。前は、しゃがむ二人をほとんど同じ構図で 21 秒見せ、ビスコはずっと同じ姿勢だった。

**案1（採用。blocking に入れた）: カットの中で 3 つに切り替える**

| 秒 | 画 | 芝居 |
| --- | --- | --- |
| 0〜7.0 | 南東の低い所から二人（寄り（二人）、55→60mm、少し寄る） | メタリカが顔を両手でおおって泣き出す（L526）。3.6 秒にビスコがちらりとメタリカを見て、5.6 秒に目をそらす |
| 7.0〜12.0 | ビスコの胸上（南の低い所から、目の高さ、45→48mm） | 7.6 秒にビスコがメタリカへ向き直る（悲しみ）。8.8 秒に手を伸ばしかけ、10.3 秒までためらい、11.3 秒に引っ込める。声は画面の外のメタリカ（L527） |
| 12.0〜21.6 | つばの下からメタリカの寄り（南東の低い所、40→48mm、`aim: eyes`） | L528。17.2 秒に顔をおおう手が胸まで下がり、泣く顔が少し見え、20.2 秒にまた顔をおおう |

切り替えのカメラは、宣言はしていないがメタリカ↔ビスコの線の同じ側（南東）に置いた。
本当にショットを分けるなら（tc・sec・voice.yaml が変わるので**案として示すだけ**）: A17-026a（tc 258.6、7.0 秒、L526）・A17-026b（tc 265.6、5.0 秒、L527）・A17-026c（tc 270.6、9.6 秒、L528）。
分けるときは `python tools/voice_yaml.py episodes/A/scenes/A17` で voice.yaml を作り直す（台詞の時刻は変わらない。カットの境目が増えるだけ）。

**案2（比べるだけ）: 1 つのカメラで続けて動く**

芝居は案1と同じ。カメラは二人の画から、ビスコの反応を入れたまま、メタリカの正面の低い所へ 21.6 秒かけて回り込み、`aim: eyes` で寄る。

```yaml
cam_keys:
- {t: 0.0, cam: [61.9, 4.8, 26.55], look: [59.7, 2.9], look_h: 27.13, lens: 55, frame: 寄り（二人）}
- {t: 8.0, cam: [61.5, 3.95, 26.75], look: [59.68, 2.8], look_h: 27.1, lens: 52}
- {t: 13.0, cam: [61.25, 3.1, 26.75], look: metallica, aim: eyes, face_y: 0.58, lens: 42, frame: 寄り}
- {t: 21.6, cam: [61.0, 2.85, 26.75], look: metallica, aim: eyes, face_y: 0.58, lens: 48}
```

比べると（Claude の見立て。最終判断はオーナー）: 案1 はビスコのためらいを独立した画で見せられ、21 秒の泣きに「聞き手の反応」という情報の変化が入る。案2 は切り替えがない分、夜会の孤立の重さが続くが、ビスコの手の芝居が小さく見える。

## A30-014「テレッサ・毒沼ですの」（15.8 秒、tc 97.3）

台詞: L1036「ぬ、沼……？これ……この臭い……ぬ、沼！？毒沼ですの……！」0.4〜11.2 秒、L1037「ひっ、ひぃぃぃ！！」11.4〜14.8 秒。前は、ほぼ横顔のテレッサの寄りを 15.8 秒（顔は画面の上の端、帽子のつばが目を隠していた）。

**案1（採用。blocking に入れた）: カットの中で 3 つに切り替える**

| 秒 | 画 | 芝居 |
| --- | --- | --- |
| 0〜6.5 | 正面の低い所からテレッサの顔（寄り、50→54mm、`aim: eyes`・`face_y: 0.6`） | 咳きこむ（0.3 秒）。3.2 秒に濡れた手を見下ろす。5.6 秒「沼！？」で驚き |
| 6.5〜9.5 | 上から、毒沼の滴る手の寄り（40→44mm） | 手を見つめる（声は続く） |
| 9.5〜15.8 | 青ざめて顔を上げるテレッサの寄り（55→60mm、目の高さの少し下） | 9.5 秒に顔を上げ、11.4 秒の悲鳴で震える（揺れを強く、11.4〜13.0 秒）、14.8 秒に泣く |

帽子のつばは、オーナー判断で前を上げた（`docs/previs_review/root_fix_phase2.md` の続き。正面・目の高さからは目元がつばに隠れない）。
本当にショットを分けるなら（**案として示すだけ**）: A30-014a（tc 97.3、6.5 秒）・A30-014b（tc 103.8、3.0 秒、手の挿し込み）・A30-014c（tc 106.8、6.3 秒、L1037）。L1036 は a から b へまたがる（声を切らずに画だけ切る）。

**案2（比べるだけ）: 1 つのカメラで続けて動く**

芝居は案1と同じ。手の挿し込みはせず、`face_y` を上げて（0.72）顔と見下ろす手を1つの画に入れ、悲鳴へ向けて寄る。

```yaml
cam_keys:
- {t: 0.0, cam: [46.09, 55.71, 1.15], look: teressa-swamp, aim: eyes, face_y: 0.6, lens: 50, frame: 寄り}
- {t: 6.5, cam: [45.95, 55.62, 1.25], look: teressa-swamp, aim: eyes, face_y: 0.72, lens: 44}
- {t: 9.5, cam: [45.85, 55.7, 1.1], look: teressa-swamp, aim: eyes, face_y: 0.6, lens: 52}
- {t: 15.8, cam: [45.75, 55.7, 1.05], look: teressa-swamp, aim: eyes, face_y: 0.58, lens: 60}
```

比べると: 案1 は「臭い → 手 → 気づいて悲鳴」の順で情報が変わり、喜劇の間が出る。案2 は顔から目を離さず、恐怖が切れ目なく高まる。
