# 下絵（previs）を作るときのチェックリスト

新しい場面の動きの設計と下絵を作るとき、これまでの見直し（A05〜A08b、`docs/previs_review/`）と決定（D-058・D-060・D-066・D-068・D-069・D-070）で直した点を、作る前と描いた後に照らす。2026-11-02 に 6章後半（A18〜）を始めるときにまとめた。見直しで新しい教訓が出たら、ここに足す。

番号の後ろのカッコは、その教訓が出た場面と見直しの番号。

## 1. 場面の頭と終わり・つなぎ（動きの設計を書く前に）

- [ ] **前の場面の終わりから、飛んで見えないか。** 場所か時間が飛ぶ所には、台詞なしのつなぎを足す（A05b→A06: 夜空から窓明かりへ下りる A06-000。A06-013→014: 稜線に戻ってくるティトの影。P-05）。
- [ ] **前の場面で去った人物が、次に出てくるまでの居場所が説明できるか。** 先に家へ駆けていったルッキーニィが、家の中に一度も映らず奥から現れた（A06 #1）。
- [ ] **場面転換を使い分ける（D-069、今後ずっと）。** 場所が変わる＝ワイプ（向きは移動の方向）、時間が飛ぶ＝暗転、同じ場面の中＝カット。切り替えの前に1秒前後の間。ショットファイルの `transition` に書く。
- [ ] **暗転の後は、頭に 0.5秒の間を置く**（A08b #3）。
- [ ] **場面の始めと終わりは引きかクレーン**（D-058）。

## 2. 台詞の選び方

- [ ] **前ふりと受けの台詞は削らない。** 見直しでは、削った台詞を戻すことが多かった（A06 で10本、A08b で4本）。後の芝居のきっかけになる台詞（ルッキーニィが先に家へ帰る理由、メタリカが「何か思いついた顔」をする理由）や、笑いの受けは残す側に倒す。
- [ ] 戻すか迷う台詞は、動きの設計のタブの「確かめたいこと」に、入れる場所と長さを書いておく。
- [ ] 原作の音源で声が見つからない台詞は使わない（A08b の L233）。ちょっとした声（悲鳴・息をのむ・百騎兵の声）は原作の声から切り出したものだけ（D-068）。

## 3. 芝居

- [ ] **6秒以上まったく動かない人物を作らない。** 長い台詞は、文の区切りで芝居を2〜3つに分ける（A06 #2: 口に手 → お辞儀 → 胸を張る）。止めの寄りも 9秒を超えたら引いて仕草を見せるか、反応のカットを挟む（A08b #4）。
- [ ] **会話の場面にも、無理のない範囲で動きを足す**（A08b: そっぽを向く、歩きながら話す、考えながら戻る、数歩踏み出す）。
- [ ] **人物の登場と大きな動きの前に溜めを作る**（D-069 (3)。A05b-016 ルッキーニィが消えてからティトが出るまで 1.5秒。A07-004 うなずく → しゃがむ → 跳ぶ）。
- [ ] **終わりの姿勢を確かめる。** ひざまずく・ひざをつくはずが立っていた（A08-006、A17-024）。
- [ ] **感情の山は顔が見える向きで終える。** 横顔や後ろ姿で終わって、うつむく芝居が見えなかった（A06 #6）。
- [ ] **音の出どころを画に入れる。** 扉を叩く音なら、揺れる扉を手前になめる（A06 #3）。
- [ ] 台詞にない場面・芝居は積極的に足す（D-066 (2)、P-05）。

## 4. 構図とカメラ

- [ ] **人物を隠すものがないか。** 手前の人物（A06 #4）、帽子のつば（A08b #6）、画面に突き出る腕（A08b #5）、棒状の持ち物（A06 #5 の松明）、手前の岩や箱（A07 #6）、家の屋根（A06 #8）、扉の枠の暗い壁（A06 #7）。
- [ ] **近すぎない・頭が切れない。** 帽子込みのメタリカは約2.4m（幻影は約3m）。`tools/frame_check.py` で足・頭の縦位置と左右の位置を数字で確かめる（A06 #9、A13〜A17 の多く）。
- [ ] **カメラが物の中に入っていないか**（A14-007 は壁の外、A14-008 は草むらの中、A17-004 は帽子の中）。描いた後に `tools/black_check.py`。
- [ ] **カメラの単調さ（同じ向き ±30° が3カット）を 0 に**（D-058、`tools/staging.py`）。向き・高さ・レンズを散らす。
- [ ] **走る・歩く人物は追いかける、感情の山は寄る**（D-058）。
- [ ] 空撮の終わりは意味のある画で止める（A06 #8: 逃げ散る松明の光と、崩れ落ちる砂柱）。

## 5. 見せ場（戦い・大きな動き）

- [ ] 溜めと解放、寄りと引きの切り替え、当たる瞬間にぐっと寄って画面を傾ける、一瞬のスロー、音を抜いてから大きな音（A07 の戦いの組み立て）。
- [ ] 主役の寄りを入れる（A07: 逆さの百騎兵の寄り、目に突き立てる瞬間）。
- [ ] 生き物や効果を、仮の形のまま写さない。設定画の色・節・トゲ、半透明の煙や盛り上がりで描く（A05-006・007、A06 #10）。動画にすると下絵の形がそのまま描かれる。
- [ ] 大きな生き物は大きさが伝わる角度で（A07 #3: 床すれすれから見上げる）。
- [ ] ピラーは守護者を倒すまで隠し、倒した直後にせり上がって現れる（D-070）。

## 6. 音（D-068・D-069 (4)）

- [ ] **BGM は原作でその場面に流れていた曲**（`docs/audio_catalog.md` の並び）。ユーザーが指定した所だけ変える。
- [ ] 効果音は CC0 の素材が中心。原作らしさが要る音は原作から切り出す。足音は `tools/footsteps.py` が置く。
- [ ] 音量は台詞を 1.0 として BGM 0.28、環境音 0.15〜0.2、足音 0.16、扉などの音 0.4〜0.6。素材の大きさをならしてから掛ける。
- [ ] 溜めの瞬間は BGM と唸りをぷつりと止め、次の大きな音で戻す（A07-013b）。
- [ ] 洞窟などの響く場所は効果音に残響（sound.yaml の `echo`）。

## 7. 通信で話す人物（D-066 (3)・D-069 (2)）

- [ ] 原作が「通信」とだけ書く場面は声だけ。話し始めに右上の小窓（ブラウン管の電源が入るように開く、無線のノイズ）を 2〜3秒。ずっと話し続ける場面は、場所が変わった所にも出す（scene.yaml の `comm.cuts`）。
- [ ] 「幻影が出てくる」と書く場面は、半分透けた幻影として画に出す。
- [ ] 通信の相手（6章後半ではマーニィ）にも同じ決まりを当てる。

## 8. 描いた後の確かめ（手順は `docs/handoff_previs_review.md` の「直し方の手順」）

- [ ] `tools/staging.py`: 軸・飛び・重なり・カメラの単調さが 0。
- [ ] `tools/frame_check.py --all`: 映すはずの人物が画面に入り、頭と足が切れていない。× の映り込みがない。
- [ ] 0.5秒ごとのコマ（`previs.py --motion 0.5`）を全部自分で見る。上の 3〜5 を照らす。
- [ ] 下絵動画 → 通し（`tools/previs_reel.py`。BGM・効果音・ちょっとした声・ワイプと暗転・小窓が入る）→ `tools/black_check.py`。
- [ ] 静止画の構図の参照は、略図でなく下絵の最初と最後のコマ（A05-001・004）。
