# BGM と効果音の一覧（名前つき）

**BGM の決まり（2026-11-01 ユーザー判断）**: 基本は、原作でその場面に流れていた曲をそのまま使う（下の「場面ごとに、ゲームが流していた曲」の並び）。ユーザーが指定した所だけ変える。

場面で「ここは M07」「ここで E03」のように番号か名前で指定してください。名前は仮なので、付け直してもかまいません。

- 試聴: Drive の「魔女と百騎兵 原作音源」の **BGM** フォルダ（`M01_魔女邸.mp3` など）と **効果音** フォルダ（`E01_扉を軽く叩く.mp3` など）。
- BGM はプレイ録画から声を分けた残り（パート16〜21）を解析して曲に分けました。似た曲が1つにまとまったり、同じ曲が2つに分かれたりしている所があるかもしれません。聞いて違ったら教えてください。
- 試聴の BGM は各曲の約45秒の切り出しです。場面で使うときは、選んだ曲からループを作ります。
- 元の一覧: `audio/bgm/catalog.yaml`、`audio/sfx/index.yaml`
