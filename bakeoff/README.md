# ベイクオフ

制作パイプラインの候補を、同じ条件で比べる。対象は A01 の性質の違う5カットと、3人の声。評価はユーザーが行い、[evaluation.md](evaluation.md) に記録する。

## 対象

| カット | 性質 | 見るところ |
| --- | --- | --- |
| [A01-001](shots/A01-001.yaml) | 背景の大引き（沼と魔女邸） | 光る緑の沼の美しさ、原作の美術との近さ |
| [A01-008](shots/A01-008.yaml) | 会話の胸上（ビスコ） | 設計書の「必ず残すもの」の再現、口パク |
| [A01-019](shots/A01-019.yaml) | 本音の寄り（メタリカ、逆光） | 表情の繊細さ、帽子のつばと光 |
| [A01-026](shots/A01-026.yaml) | ギャグの動き（デフォルメの蹴り） | デフォルメの一貫性、動きの切れ |
| [A01-038](shots/A01-038.yaml) | 反応（百騎兵の首かしげ） | 兜と同心円の目、炎の再現 |

声: [メタリカ](voices/metallica.yaml)、[ビスコ](voices/bisco.yaml)、[アルレッキーノ](voices/arlecchino.yaml)。各3台詞。

## 手順

1. **声（いちばん安いので先に）**: 3人の声を設計して作り、各3台詞を読ませる。
   - `python tools/gemini_tts.py design bakeoff/voices/metallica.yaml` … 声を作り、試聴用の音声と `voice_id` を保存
   - `python tools/gemini_tts.py speak bakeoff/voices/metallica.yaml` … テスト台詞を読ませる
   - 出力は `bakeoff/results/voice/<人物>/`
2. **静止画**: 5カットを、画像の候補ごとに作る。1カット3回まで生成し、いちばん良い1枚で評価する。
3. **動画**: 各カットで最も良かった静止画を、全候補に共通の最初のフレームにする。入力をそろえるので、動きの差だけが見える。
4. **記録**: 生成のたびに `tools/record.py` で記録する。評価表に点数、費用、時間、気づいたことを書く。

どの段階でも、生成の前にカット・モデル・指示文・本数・概算費用を示して、ユーザーの承認を得る（CLAUDE.md）。

## 出力の置き場所

```
bakeoff/results/
  image/<カットID>/<モデル>_<連番>.png
  video/<カットID>/<モデル>_<連番>.mp4
  voice/<人物>/<design|テストID>.wav
```
